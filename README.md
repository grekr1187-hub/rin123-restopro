# RestoPro

Премиальная русскоязычная POS/Restaurant OS для ресторана и кафе — без iiko.

## Что есть

- Главная с KPI, выручкой, динамикой продаж и рейтингом официантов.
- Касса и заказы: стол, официант, блюда, статусы, оплата и чек.
- Зал и столы: свободен / занят / бронь / уборка.
- Меню: категории, цены, себестоимость и фото блюд.
- Кухня и бар: очереди приготовления.
- Склад и закупки: остатки и низкие уровни.
- Техкарты, персонал и отчёты.
- Excel-экспорт.
- AI-Manager с POS-контекстом.
- Telegram-интеграция.
- Термопринтеры: системная печать и Web Serial в поддерживаемых браузерах.
- PWA: установка на моноблок, ПК, планшет и телефон.
- RU / UZ / EN и UZS / USD / RUB.
- PostgreSQL как постоянное хранилище.

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## Установка на моноблок

Откройте приложение в Chrome или Edge → меню браузера → **Установить RestoPro**. После установки оно запускается отдельным окном как рабочее приложение.

## Railway

Railway должен запускать `npm start` и проверять `GET /health`.

Не храните секреты в GitHub. Для AI и Telegram используйте Railway Variables:

- `DATABASE_URL`
- `OPENAI_API_KEY`
- `OPENAI_MODEL`
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

## Термопринтер

На Windows/моноблоке можно выбрать обычный системный термопринтер через диалог печати. В Chrome/Edge с Web Serial поддерживаемый USB/Serial принтер можно подключить непосредственно из раздела **Принтеры**.
